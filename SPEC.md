# kami-lens — Contract Registry

What kami-lens promises, what it consumes, and what holds. This is a
registry, not a description of the implementation: every row is a
falsifiable claim and names the thing that would catch it breaking.

`unenforced` is a legal value in the enforcement column and appears
wherever it is true — an empty cell is not. Rationale lives in
[DESIGN.md](DESIGN.md); per-surface release status in
[docs/coverage.md](docs/coverage.md); gate definitions in
[PORT_PLAN.md](PORT_PLAN.md). Where DESIGN states the principle, the
row cites the section rather than restating it.

Gate scripts are `gates/g<N>.sh`; `[live]` parts write dated evidence
to `docs/measurements/`. G0 is the hermetic gate CI runs on every
push.

## 1. Provides

### 1.1 Query surface

Twenty-four named queries, plus `status` and one stateless variant.
The authority for what a release serves is the zero-TBD table in
[docs/coverage.md](docs/coverage.md); this table is the contract form
of it. *Needs* is what must be reachable for a non-error answer:
`mirror` = a synced daemon, `kamiden` = the feed service.

### 1.2 Response envelope

| Claim | Enforcement |
|---|---|
| Every response — CLI, socket, or library — is `{data, untrusted: [paths], meta}`. Envelope delivery *is* the contract consumers rely on; there is no unwrapped path. | G3.f; `test/envelope.test.ts`; DESIGN §3.10 |
| `untrusted` lists the dot/`[]` paths of authored-class strings **present** in `data`; an empty list is a legal answer, never an omission. | G3.f; `test/envelope.test.ts` |
| The list is derived from (checked-in output schema × `docs/string-classification.json`), never hand-maintained; divergence fails CI. | G3.f |
| `meta` carries `servedAt`, `blockNumber`, `stale`, `mode` (`daemon`\|`stateless`), `asOf` (0.5.2), and `suppressed` when anything was withheld. | G3.a (status/meta schema), G3.e (`stale` under degradation), G3.f + G6.c (`suppressed`) |
| **`meta.asOf` says when this answer's projections were computed, and on what evidence (0.5.2).** One object, the same shape on EVERY answer, stamped in the single place every answer passes through: `block` (the mirror's lower bound, same value as `meta.blockNumber`), `projectedAtSec` (the offset-corrected instant the projection math used), `observedBlock` / `observedBlockTime` (the block whose header timestamp produced the current clock correction — a DIFFERENT, older block than the mirror's newest), `clockOffsetMs`, and `observedAgoMs`. | structural (`buildAsOf`, `src/queries/envelope.ts`); DESIGN §3.8 |
| **The fields are separate and never fused into one "as of" claim.** The mirror block and the clock anchor are two different blocks; presenting them as one instant would be a lie of convenience. **The last four are ABSENT TOGETHER until the first clock observation** — before it the offset is 0 because nothing was measured, not because the clocks agree, and a served `clockOffsetMs: 0` would read as evidence (§3.14; the §3.15 head-fields precedent). | structural (`buildAsOf`, `src/queries/envelope.ts`) |
| **`asOf` exposes the clock; it does not change it.** 0.5.2 alters no projected value — those are parity-gated against the reference client — even though the correction was measured running 14.2–15.3 s behind chain head time and stepping ~10 s between observations (DESIGN §3.8). The release that measures a thing is not the release that acts on it. | G2.b (display parity, unchanged); G3.g (no `data` leaf moved) |
| **`degraded` is CHAIN health; `feedsDegraded` is KAMIDEN feed health (0.5.2).** `degraded` covers the chain mirror — `stream-stalled:<N>s`, `pre-live-stall:<N>s`, and any nonzero tripwire — and it alone drives `meta.stale`. `feedsDegraded` carries `kamiden-stream:<state>` whenever the stream is not live and `kamiden-silent:<N>s` past 60 s, and drives nothing. **A caller gating on `degraded` alone is NOT covered for the nine Kamiden-backed reads** (`killers`, `battles`, `trades`, `auctions`, `market`, `portal`, `transfers`, `feed`, `chat`) — read `feedsDegraded` before trusting those. Both are always present; an empty array is an answer. | G3.a (schema); DESIGN §3.2 |
| **A rising Kamiden `retries` count is healthy.** The production server closes the subscription roughly every 40 s by design, so `feedsDegraded` keys on stream STATE and SILENCE, never on the reconnect count, and the gRPC text it logs ("Response closed without grpc-status (Headers only)") is the expected server-side close at this pin — measured 2026-07-21 and again 2026-08-27, not an upstream change. | G4.b (the error string is recorded verbatim in its 2026-07-22 measurement) |
| **`meta.blockNumber` is a LOWER BOUND** (§3.15): the highest block whose updates the mirror had applied when the answer began building, captured at dispatch. A long answer may include state from later blocks, never earlier ones; the number does not advance for a block that produced no world events, and it is not a read-your-writes guarantee. | structural (`getMirror`, `src/daemon.ts`; `serveQuery`, `src/queries/index.ts`); **unenforced** — no gate asserts the bound |
| **On a Kamiden-sourced answer, `meta.blockNumber` describes the MIRROR, not the feed.** `market`, `trades` history, `battles`, `portal` and `transfers` carry rows from a service with its own independent lag, joined against mirror state; the stamp is honest about the join and says nothing about the freshness of the service's rows. | structural; DESIGN §3.15 |
| Values inside `data` are verbatim: never truncated, rewritten, or normalized. | G4.c (oversize withhold-with-receipt, `--oversize` serves verbatim); DESIGN §3.10 |
